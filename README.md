# Бот расписания Политеха (Telegram)

Бот сам заходит на страницу с кнопками «Расписание на Понедельник … Субботу», берёт актуальные
ссылки на Облако Mail.ru, скачивает xlsx, вырезает расписание нужной группы и отправляет
в Telegram. Когда на сайте появляется новая ссылка или меняется содержимое файла, бот
рассылает обновление только тем, кто выбрал затронутую группу.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. `pip install -r requirements.txt` (Python 3.10+)
3. `cp .env.example .env` и впишите `BOT_TOKEN` (и свой ID в `ADMIN_IDS`).
4. **Сначала проверьте сетевую часть:** `python check_fetch.py`.
   Скрипт покажет найденные ссылки и скажет, скачивается ли каждый файл с Облака.
5. `python bot.py`

Для работы 24/7 нужен сервер или VPS. Пример `systemd`-юнита:

```ini
[Unit]
Description=Politex schedule bot
After=network-online.target

[Service]
WorkingDirectory=/opt/politex_bot
ExecStart=/opt/politex_bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## Как пользоваться

- `/start` → выбрать улицу колледжа → курс → группу → кнопки «Сегодня», «Завтра», «Выбрать дату».
- 🎮 «Игровая зона»: виртуальный баланс (стартовые 1000 монет), рулетка, ежедневный бонус 10–1000 монет, топ-20 игроков и крестики-нолики. Казино удалено. Это развлекательные виртуальные монеты: переводов и вывода реальных денег нет.
- Под расписанием есть стрелки на соседние даты.
- «Уведомления» включают и выключают автоматическую рассылку.
- **Групповой чат:** добавьте бота в чат, напишите `/start`, группу выбирает админ чата.
  Новые расписания будут приходить прямо в чат.
- Админские команды (`ADMIN_IDS`): `/status` (состояние) и `/refresh` (проверить сайт сейчас).

## Как это устроено

| Файл | Что делает |
|---|---|
| `fetcher.py` | находит ссылки на страницах обоих корпусов, скачивает xlsx с Облака Mail.ru |
| `schedule_parser.py` | разбирает Excel .xls/.xlsx обоих корпусов: группы, пары, аудитории, преподаватели, «с 12-40» |
| `watcher.py` | раз в 5 минут проверяет сайт, сравнивает с сохранённым и рассылает изменения |
| `storage.py` | SQLite: чаты, ссылки, расписания по датам |
| `render.py`, `bot.py` | оформление сообщений и интерфейс бота |

- Первый запуск рассылку не делает: бот молча загружает текущие расписания.
- Уведомление приходит, только если расписание **этой группы** изменилось. Если у группы в новый
  день занятий нет, сообщения не будет.
- Расписания хранятся 30 дней, поэтому прошедшие даты можно открыть.

## Если перестало работать

- Не скачивается файл: Mail.ru мог поменять схему выдачи. Правится одна функция,
  `download_mailru` в `fetcher.py`. Админ получает уведомление об ошибке (не чаще раза в 6 часов).
- Не находятся кнопки: сайт могли перестроить. Правится `fetch_day_links` в `fetcher.py`.
- Изменился формат таблицы: тест `python test_logic.py` разбирает `samples/monday.xlsx`,
  туда можно положить новый пример.

## Хостинг на Render (бесплатный)

- Создавайте **Web Service** (Start command: `python bot.py`), Render сам задаёт переменную `PORT`,
  и бот поднимет на ней мини-сервер, который отвечает `ok`.
- Бесплатный сервис засыпает через 15 минут без входящих запросов. Заведите на
  [UptimeRobot](https://uptimerobot.com) или [cron-job.org](https://cron-job.org) пинг
  `https://ВАШ-СЕРВИС.onrender.com/` каждые 5 минут.
- Файловая система на бесплатном Render **временная**: после перезапуска или деплоя `bot.db`
  стирается, и пользователям придётся заново выбрать группу. Для постоянной работы нужен диск
  или внешняя БД, либо VPS.


## Игровая зона: крестики-нолики

В игровом меню есть кнопка «❌⭕ Крестики-нолики». Игрок нажимает «Найти соперника»,
после чего попадает в очередь; когда второй игрок ищет матч, обоим отправляется игровое поле
в личный чат с ботом. Победитель получает +300 виртуальных монет, проигравший — +50.
При ничьей оба получают +50. Для уведомления соперника оба игрока должны заранее открыть
личный чат с ботом и нажать `/start`. Очередь и активные матчи хранятся в памяти и очищаются
при перезапуске бота.


## Игровая зона

В игровом меню есть баланс, рулетка, ежедневный бонус, топ-20 и крестики-нолики. Казино/слот-машина удалены.
В топе отображается @username как кликабельная ссылка, если он задан в Telegram; иначе — имя-ссылка на профиль по ID.

## После обновления парсера

Запусти `/refresh`: эта команда повторно разбирает файлы, даже если их ссылки и содержимое не менялись. Это важно, чтобы исправления парсера применились к уже сохранённым расписаниям.
